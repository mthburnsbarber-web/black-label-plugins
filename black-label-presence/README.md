# Black Label Presence

Local stdio MCP and skill for durable agent-executed presence work. 14 tools cover the site catalog, idempotent runs, amendments, leases, account observations, staging/review, publication reservations, readback receipts and exports.

All 57 destinations are listed in [COVERAGE.md](COVERAGE.md). Public defaults ship without account identities, private plans, assets or observed results. Set `BL_PRESENCE_REGISTRY` to an absolute private registry file for custom requirements and account candidates. Set `BL_PRESENCE_STATE` to override the default private state directory `~/.blacklabel/presence`.

Use `presence_run` → `presence_next` → actual browser action → `presence_record`. Posts use stage → factual/visual review → prepare → actual submission/readback → publication result. A returned work order has not performed an external action. Unknown results retain duplicate reservations; independent sites can continue.

The lint catches common filler, excessive hashtags, missing media and near-duplicate text. Factual accuracy, visual quality and contextual originality still require the agent's actual inspection. Results are agent observations, not independent provider attestations. See the repository [README](https://github.com/mthburnsbarber-web/black-label-plugins#readme), [PRIVACY.md](PRIVACY.md) and [VERIFICATION.md](VERIFICATION.md).
