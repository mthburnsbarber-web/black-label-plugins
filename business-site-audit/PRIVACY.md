# Business Site Audit data handling

The plugin sends the public URL you supply to the declared Business Site Audit MCP server at `https://audit-mcp.blacklabelbots.com/mcp`. Black Label operates that server on Cloudflare Workers. The server requests the supplied public page, its robots.txt, and its sitemap or redirects, then returns the dated report to your AI host. The audited site and network providers can see those ordinary public HTTP requests and the disclosed `BusinessSiteAudit/1.1` user agent.

The server receives the supplied URL and Cloudflare processes the calling client's IP address and operational request metadata to deliver and protect the service. The URL can itself contain personal information if you put it in a path or query string. The server uses the URL only to make the public checks and return the report. It does not use analytics cookies, ask for an account, read local files, or read credentials. Black Label does not store audit inputs or reports in a database or deliberately log tool arguments or report bodies.

The per-IP rate limiter counts requests for a 60-second window. Cloudflare Workers Logs and Traces are enabled for operational diagnosis and may contain request or subrequest metadata, including public target URLs. Cloudflare's published retention is [three days on Workers Free and seven days on Workers Paid](https://developers.cloudflare.com/workers/observability/logs/workers-logs/#pricing); operational events are retained for no more than seven days under those plan limits. The audited website and network providers also receive ordinary public HTTP requests and may keep their own logs under their policies. Your AI host handles the returned report under its own policy.

The tool rejects URL credentials, IP-literal targets, non-default ports, private hostnames, and private or reserved DNS answers. Redirects are rechecked. Public HTTP GET/HEAD is the only site action. Do not submit private links or tokens in query strings; the submitted URL is sent to the server.

You control which public URL you submit. There is no Business Site Audit account or stored report to view or delete; the rate-limit count expires after 60 seconds and Cloudflare operational events expire under the retention period above. For data-handling questions, [open a support issue](https://github.com/mthburnsbarber-web/black-label-plugins/issues) with the URL and any personal details redacted.
